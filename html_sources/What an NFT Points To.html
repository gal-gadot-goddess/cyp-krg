What to learn

🔗 NFT = token + pointer. The art usually lives somewhere else.
🕳 Web URLs rot or get swapped. The owner of the server controls the file.
🧬 Content addresses fix it. The link is the hash, so changes are detectable.
📌 Check before you buy. Look at tokenURI and where the files are pinned.
